### Project Outline:

A simple college planner/productivity app with a planner, grade tracker, study timer, and job tracker. Users will be able to create accounts and login to access each page as well as save information associated with their profile through submission forms which can be added to, modified, and/or deleted. Key technologies we plan on using are React, JavaScript, Node.js, MongoDB, and possibly a CSS styling template. This project aims to provide a support application to help students stay organized in their classes, job applications, and time management.

One way to achieve server-side computation is with the job tracker: the server could add a column showing how long ago the user submitted the application and include a note reminding them when to follow up. This could be applied to Planner as well: a column showing time left before the deadline, or dynamically sorting the list of tasks based on urgency/deadline. For the grade tracker, a grade calculator could also be integrated, which calculates a specific grade needed in order to achieve an A/B/C in a specific class.
